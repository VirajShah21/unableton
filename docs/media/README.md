# README media

`hero.svg` and `ai-workflow.svg` are original vector graphics for this repository. They use system fonts and contain no external resources or scripts.

The JPEGs are unmodified native app captures from macOS 26. They show a purpose-made, locally prepared demonstration arrangement using only the six built-in sounds. The demo is not a live AI-generation result, and the visible refinement prompt is unsent. No personal songs, saved chats, credentials, sampled banks, or recordings appear in the captures.

The interface can change between versions. Update the captures when relevant workflows change. Code and repository-created graphics use the root Apache 2.0 license; source-provider instrument credits remain in THIRD_PARTY_NOTICES.md and the catalog.
